お店のGoogleマップ（ビジネスプロフィール）の整え方と、紹介文の書き方

2026.11.25 公開　｜　ラムラム（京都・元銀行員）

「近くのカフェ」「京都 ネイル」のように、地図で探す人はたくさんいます。そのときに表示されるのが、Googleマップのお店の情報（Googleビジネスプロフィール）です。

無料で使えて、整えるだけで見つけてもらいやすくなります。この記事では、まずやっておきたいことをまとめます。

まず、自分のお店として登録されているか確かめる

Googleマップでお店の名前を検索してみてください。すでに表示されていても、お店の方が管理者になっていないことがあります。管理者になると、営業時間や写真、紹介文を自分で直せるようになります。登録や本人確認の方法は、Googleの案内に沿って進めてください。

整えておきたい5つのこと

  1. 営業時間と定休日（臨時休業もその都度）
  2. 電話番号とホームページのアドレス
  3. お店の紹介文
  4. 写真（外観・店内・メニュー）
  5. 予約やメニューへのリンク

特に営業時間は、ホームページやグルメサイトと食い違わないようにしておくことが大切です。

紹介文の書き方

紹介文は750文字まで書けます。ただ、最初に目に入るのは冒頭の数行です。

書く順番の例
1. どんなお店か（ひとことで）
2. いちばんのおすすめ
3. どんな人に来てほしいか
4. 予約の方法や、来る前に知っておいてほしいこと

「地域No.1」のような根拠のない言葉や、大げさな表現は避けましょう。読んだ人が「行ってみよう」と思えるかどうかを大切にしてください。

写真は、来る前の不安を消す順番で

外観の写真があると、初めての人が迷いません。次に店内、そしてメニューや料理の写真。看板のないお店や、建物の上の階にあるお店は、入口の写真を必ず入れておくと親切です。

やってはいけないこと

  • 口コミをお金や特典と引き換えに書いてもらうこと（Googleのルールに反します）
  • 店名に地名やキーワードを付け足すこと

紹介文づくりを手伝っています

「何を書けばいいか分からない」という方のために、ラムラムでは紹介文をお作りするサービスもしています。お店のホームページとあわせて整えると、地図から来た人にも詳しい情報が届きます。

よくある質問

Googleマップの登録にお金はかかりますか？

登録や情報の編集は無料です。

自宅で営業していて、住所を出したくありません。

住所を表示せず、対応している地域だけを表示する設定ができます。詳しくはGoogleの案内をご確認ください。
